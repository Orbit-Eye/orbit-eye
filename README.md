## ORBITEYE

Projeto desenvolvido para a disciplina de **Web Development** da FIAP - Global Solution.

---

## Sobre o Projeto

O **OrbitEye** é uma aplicação web interativa voltada ao monitoramento ambiental através de tecnologia orbital, inteligência artificial e análise de dados espaciais.

A plataforma foi desenvolvida com foco em:

- prevenção de queimadas;
- monitoramento em tempo real;
- análise de focos de calor;
- visualização estratégica de dados ambientais.
